# Sillytavern-Character-Expressions-Helper
A small helper plugin to control the default character expressions extension in sillytavern. Needs my custom preset to work.

Basically, what the chat completion preset does is fetch available sprites from the default character expressions extension, and determine the form the character is in. Form is basically the subfolder anointed through the helper.
